# 收录与核验方法

## 目标

DSH Plugins 的目标不是复制所有带 `dsh-plugin` 标签的仓库，而是帮助读者快速判断：一个项目具体做什么、适合谁、怎样安装、使用时最容易踩什么坑。

本轮核验日期为 **2026-08-15**。DeepSeek Harness 仍处于 Developer Preview，任何兼容结论都可能随新版本变化。

## 候选来源

候选项目主要来自以下入口：

1. DeepSeek Harness 官方仓库与官方推荐的 `dsh-plugin` Topic；
2. GitHub Search API 按 Star 排序的公开仓库；
3. 社区维护的 Awesome DSH Plugin 列表；
4. 插件作者自己的 README、Release、安装文档和兼容矩阵；
5. 近期社区讨论，只作为“新锐观察”的线索，不单独支撑成熟度结论。

## 基础门槛

项目进入候选池至少需要满足：

- 公开可访问的源码仓库；
- 明确的 DSH 接入方式：Bundle、Skill、Preset、主题或整合包之一；
- README 中能找到用途与安装路径；
- 最近仍有维护信号，或具有无法被同类项目替代的独特能力；
- 风险、许可或成熟度不确定时可以被明确标注。

## 分层规则

### 热门精选

- 本次快照至少 100 Star；
- 存在可核验的 DSH 接入说明；
- 按快照 Star 从高到低排列；
- Star 只表示关注度，不代表代码质量、安全或兼容性。

### 新锐观察

- 未达到 100 Star；
- 发布很新，或有近期社区讨论；
- 具备独特且清晰的使用场景；
- 必须显式提醒读者其成熟度较低。

## 证据等级

| 等级 | 证据 | 用法 |
|---|---|---|
| 高 | 官方 DSH 文档、项目源代码、项目 README、Release、GitHub API 原始数据 | 支撑功能、安装、版本与仓库状态 |
| 中 | 社区精选列表、作者发布帖 | 辅助判断可发现性、近期关注与使用场景 |
| 低 | 转述、截图、无原始链接的评论 | 只作为搜索线索，不写入确定结论 |

## 反证检查

定稿前对每个候选项目检查：

- 是否只是给一个既有项目补了 `dsh-plugin` Topic；
- 是否真的存在 DSH 安装说明或可发现的 Skill/Preset；
- README 的性能数据是否只来自单一任务；
- 安装是否会执行远程脚本、构建脚本或获得广泛本机权限；
- 是否把“收录”“Star 多”或“作者自述”误写成安全审计；
- 是否存在许可证、版本兼容或外部服务依赖等重要限制。

## 更新规则

更新一次快照时需要：

1. 重新获取 Star、Fork 与最后 Push 时间；
2. 检查 README 的安装命令和兼容版本；
3. 更新 `data/plugins.json` 与 README 中对应描述；
4. 运行 `npm run validate`；
5. 在 PR 中说明新增、删除、升级或降级的证据。

## 不做的承诺

- 本项目不承诺插件安全；
- 不承诺在所有操作系统或 DSH 版本上可用；
- 不承诺 Star 排名等于质量排名；
- 不对第三方插件造成的数据、费用或环境损坏承担责任；
- 不接受付费换位或未披露的商业排序。
